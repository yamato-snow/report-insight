# デモ動画 台本（3〜5分・目標 4:00）

- 素材: `scripts/demo_capture/` で撮影した無音キャプチャ（webm/mp4）。各カットの素材名は表の右列
- 収録: 画面素材を並べた編集タイムラインに合わせてナレーションを読む（QuickTime / OBS + 任意の編集ソフト）
- 秒数は目安。**素材の実尺を優先し、ナレーションが追いつかないカットは素材側を静止延長する**

## 収録のコツ・逃げ道

- **言い直しはカット単位で**。素材が無音なので、ナレーションだけ録り直せばよい
- 検索の回答文は毎回変わる（実API）。台本は「引用つき・3秒以内」など**型にだけ言及**し、文言に依存しない
- 月次生成が2分を超えたら素材を撮り直す（`--scene monthly`）。未分類キューが尽きたら `make demo` 再シード
- 尺が5分を超えそうなら 0:25–0:55（取込・分類）を圧縮する。3分に縮めるなら検索の該当なしカットを落とす
